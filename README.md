# Smart Student Timetable & Free-Slot Manager

## 1. Project Overview

The **Smart Student Timetable & Free-Slot Manager** is a terminal-based Python application designed to help students organize and manage their weekly academic timetable.

The application allows users to add, view, search, and remove classes while also detecting timetable clashes and identifying available free-time slots. It also provides basic timetable analytics such as the total number of classes, scheduled class-hours, number of clashes, and the busiest day.

The project demonstrates fundamental Python programming concepts including lists, dictionaries, tuples, functions, classes, loops, conditional statements, searching, sorting, input validation, exception handling, and modular programming.

---

## 2. Problem Statement

Students often have multiple lectures, laboratory sessions, and academic activities scheduled throughout the week. Managing these activities manually can make it difficult to maintain an organized timetable, identify overlapping classes, and find available free time.

This project provides a simple terminal-based solution that allows students to manage their weekly timetable and analyze their schedule.

---

## 3. Objectives

- Organize weekly academic classes in one timetable.
- Allow users to add, view, search, and remove classes.
- Detect overlapping classes scheduled on the same day.
- Identify available free-time slots.
- Provide basic timetable analytics.
- Validate user input and handle invalid information.
- Apply Python programming concepts through a practical project.
- Maintain a modular and organized project structure.
